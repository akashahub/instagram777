# Instagram 777 - Biblioteca de Posts

Organize seus posts do Instagram antes de postar.

## Como usar
1. Abra o index.html (ou ative GitHub Pages)
2. Cole o link do vídeo
3. Escreva a legenda
4. Salve e veja o preview estilo Instagram
5. Copie a legenda quando for postar

Dados salvos no navegador (localStorage).

Repo: https://github.com/akashahub/instagram777

Para ficar em akashahub.com.br/instagram777, configure o CNAME ou GitHub Pages com custom domain.
